# SkillChain — The AI-Powered Skill Ecosystem

A comprehensive platform where users can teach, learn, and exchange skills using SkillCoins with AI-powered features and premium subscription tiers.

## 🚀 Features

### 🤖 **AI-Powered Learning**
- **AI Smart Skill Value Calculator** - Python FastAPI backend for skill valuation
- **AI Learning Assistant** - Personalized AI tutor with subscription-based access ($99/month)
- **AI Recommendations Dashboard** - Personalized learning paths
- **Multilingual AI Voice Bot** - Speech-to-text and translation
- **Reels & AI Learning Q&A** - Video-based learning with voice AI assistance

### 💰 **Premium Subscription Tiers**
- **AI Assistant Subscription** - $99/month for AI-powered learning features
- **SkillPro Basic** - $299 for advanced AI analysis and custom learning paths
- **SkillPro Premium** - $499 for full premium features including 1-on-1 mentoring

### 🎯 **Core Platform Features**
- **SkillGraph Network Visualization** - Interactive skill network with D3.js
- **Verified Skill Demos** - Peer portfolios and skill verification
- **TimeToken Exchange** - Secure escrow system for skill trading
- **Gamification** - Challenges, badges, and leaderboards
- **Real-world Skill Map** - Google Maps integration
- **Dispute Resolution** - Review and conflict resolution system

## 🏗️ Architecture

```
skillchain/
├── frontend/                 # React + TailwindCSS + Framer Motion
├── backend/                  # Node.js + Express
├── ai-api/                   # Python FastAPI + OpenAI/Gemini
├── database/                 # PostgreSQL + MongoDB schemas
├── mobile/                   # React Native mobile app
├── docs/                     # Documentation
└── deployment/               # Docker + deployment configs
```

## 🛠️ Tech Stack

- **Frontend**: React, TailwindCSS, Framer Motion, D3.js
- **Backend**: Node.js, Express, Socket.io
- **AI**: Python, FastAPI, OpenAI API, Gemini API
- **Database**: PostgreSQL, MongoDB
- **Auth**: Supabase
- **Hosting**: Vercel (Frontend) + Render (Backend) + Railway (AI API)
